# Django BookReview Project

A simple BookReview web application developed using Python and Django. This project allows users to explore book details and organize books by genre.

## Features

- Add book details
- Store book title, author, genre, description, and ISBN
- Filter books by genre
- View book details
- Use Django forms to manage book information

## Technologies Used

- Python
- Django
- HTML
- CSS
- SQLite
